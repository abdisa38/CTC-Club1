**Figma AI Prompt — Student Dashboard (Brief)**

Design a **modern student dashboard UI for an online exam and gaming platform** with a **blue branding theme**. The layout should be **clean, responsive, and AdSense-friendly**, with clear areas for advertisements.

**Main Features to Include:**

**1. Dashboard Overview**
Show summary cards for:

* Total exams available in the student’s preferred category
* Gaming mode points earned
* Number of games played
* Recent exam attempts

**2. Exam Section**
Students can:

* View available exams based on their selected category (Grade 8, Grade 12, CoC, Exit Exam, General Knowledge)
* Start exams
* View past exam results

**3. Gaming Mode**
Gaming Mode is a **premium feature**.
Show:

* Points earned
* Gaming history
* Leaderboard preview

Each gaming question includes:

* **Timer per question**
* **Points based on question weight**

**4. Profile Management**
Students can **view and edit profile details**:

* Name
* Phone number
* Telegram ID
* Exam category preference

**5. Feedback & Rating**
Provide a section where students can:

* Give **1–5 star ratings**
* Submit **feedback comments**

**6. Advertisement Placement**
Include **AdSense-friendly ad areas**:

* Top banner ad
* Left sidebar ad
* Right sidebar ad
* In-content ad blocks

**Layout Structure**

* Top navigation bar
* Left sidebar navigation (Dashboard, Exams, Gaming Mode, Leaderboard, Profile, Feedback)
* Main content area
* Right sidebar for ads

Use **modern card components, clean tables, and a blue color theme suitable for an educational platform**.
